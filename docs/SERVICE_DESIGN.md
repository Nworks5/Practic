# Описание работы программы (Бизнес-логика)

Этот документ описывает главные правила работы программы Timetracker. Здесь написано, как приложение проверяет данные, защищает информацию от удаления и что оно делает при ошибках.

## 1. Главные операции программы

### Операция 1: Остановка таймера и сохранение времени 

*   **Что делает:** Считает, сколько минут студент потратил на задачу, записывает это время в историю и удаляет задачу из временного окна активного таймера.
*   **Что получает на вход:** Номер таймера и точное время нажатия кнопки «Стоп».
*   **Используемые запросы к БД:**
    Найти запущенный таймер в таблице `timer`
    Добавить новую запись времени в таблицу `time_logs`
    Удалить старый таймер из таблицы `timer`
*   **Проверка:** 
    * Время кнопки «Стоп» не может быть раньше, чем время старта.
    * Потраченное время должно быть больше 0 минут.
*   **Что будет при ошибке:** Если компьютер заглючит во время записи в историю, программа остановит процесс и сохранит запущенный таймер. Студент не потеряет свои набежавшие минуты.

### Операция 2: Безопасное удаление задачи 

*   **Что делает:** Удаляет задачу из списка дел, но только если по ней еще нет записанного времени. Это защищает историю подготовки от случайного удаления.
*   **Что получает на вход:** Номер задачи.
*   **Используемые запросы к БД:**
    Посчитать количество записей в таблице `time_logs` для этой задачи
    Удалить саму задачу из таблицы `task`
*   **Проверка:** 
    * Если по задаче есть хотя бы одна минута в истории, удалять её строго запрещено.
*   **Что будет при ошибке:** Если студент попытается удалить задачу с историей, программа покажет предупреждение: *"Нельзя удалить запись задач уже с существующими записями времени"*.

### Операция 3: Фильтрация отчета по датам 

*   **Что делает:** Собирает все записи времени за выбранные дни, складывает минуты и показывает отчет (какая задача сколько времени заняла).
*   **Что получает на вход:** Дата начала и дата конца.
*   **Используемые запросы к БД:** Запрос `getFilteredTimeReport` собирает задачи из таблицы `task` и складывает их минуты из таблицы `time_logs` за период.
*   **Проверка:** 
    * Поля дат не должны быть пустыми.
    * Начальная дата не может быть позже конечной.
*   **Что будет при ошибке:** Если за эти дни студент ничего не учил, программа не упадет, а просто вернет пустой список. Экран покажет текст: *"В заданном периоде нет записей"*.

### Операция 4: Создание задачи и привязка к теме 

*   **Что делает:** Создает новую задачу для учебы. Если студент не выбрал существующий предмет (заметку), программа сама автоматически создаст новую тему-категорию.
*   **Что получает на вход:** Текст задачи, номер готовой заметки или имя для новой заметки.
*   **Используемые запросы к БД:**
    1. Создать новую строку в таблице `notes` (если темы еще нет)
    2. Создать новую задачу в таблице `task` со ссылкой на заметку
*   **Проверка:** Название задачи не должно быть пустым.
*   **Что будет при ошибке:** Если не удалось создать тему или задачу, операция отменяется полностью, чтобы в базе не появлялся мусор.


## 2. Тест-кейсы (Проверка программы)

### Тесты для Таймера (Операция 1)
*   **Тест 1.1 (Всё хорошо):** Старт был в 12:00, стоп в 12:45. Программа посчитала 45 минут, записала в историю и очистила таймер.
*   **Тест 1.2 (Неверные данные):** Старт в 12:00, а время стопа ввели 11:30 (перевели часы назад). Программа выдаст ошибку и ничего не запишет.
*   **Тест 1.3 (Сбой базы данных):** База данных зависла во время сохранения. Программа отменила запись, но оставила таймер тикать, чтобы минуты не пропали.

### Тесты для Удаления задач (Операция 2)
*   **Тест 2.1 (Всё хорошо):** Задача новая, времени на неё не тратили. Кнопка удаления сработала, задача исчезла.
*   **Тест 2.2 (Защита данных):** По задаче есть 3 записи в истории. Студент жмет «Удалить». Программа блокирует это действие и оставляет задачу на месте.
*   **Тест 2.3 (Повторное удаление):** Попытка удалить задачу, которой уже нет в базе. Система просто ответит, что задача не найдена.

### Тесты для Фильтра отчетов (Операция 3)
*   **Тест 3.1 (Всё хорошо):** Выбрали период за понедельник. База нашла задачу «Лабораторная» и показала: «45 минут».
*   **Тест 3.2 (Перепутаны даты):** Студент указал поиск от 20 октября до 12 октября. Программа выдаст ошибку *"Некорректный диапазон дат"*.
*   **Тест 3.3 (Нет данных):** Студент искал отчет за день, когда не включал трекер. Программа выдаст пустой экран с текстом *"В заданном периоде нет записей"*.
