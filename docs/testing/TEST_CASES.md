Функция 1: Работа с таймером
Кейс 1. Позитивный: Обычная остановка таймера
Связанная функция: Остановка таймера и сохранение времени.
Приоритет: Высокий.
Предусловия: Пользователь запустил таймер для задачи «Лабораторная» в 12:00.
Тестовые данные: Задача номер 1, время остановки — 12:45.
Шаги выполнения:
Нажать кнопку «Стоп».
Посмотреть на список истории времени.
Проверить, исчез ли активный таймер с экрана.
Ожидаемый результат:
Программа подтвердила действие.
В истории появилась новая запись длительностью 45 минут.
Таймер перестал тикать и пропал из активных.
Постусловия: Время учтено, программа готова к новой задаче.
Кейс 2. Негативный: Попытка остановить раньше старта
Связанная функция: Проверка корректности времени.
Приоритет: Высокий.
Предусловия: Пользователь запустил таймер для задачи «Лабораторная» в 12:00.
Тестовые данные: Задача номер 1, указанное время остановки — 11:30 (раньше старта).
Шаги выполнения:
Попытаться сохранить сессию с временем стопа 11:30.
Ожидаемый результат:
Программа выдает ошибку: «Время остановки не может быть раньше начала».
Данные не сохранились, таймер продолжает работать (или остался активным в системе).
Постусловия: История времени не изменилась.
Кейс 3. Граничный: Нулевая длительность
Связанная функция: Проверка минимального значения времени.
Приоритет: Средний.
Предусловия: Пользователь запустил таймер для задачи «Лабораторная» в 12:00.
Тестовые данные: Задача номер 1, время остановки — 12:00 (точно такое же, как старт).
Шаги выполнения:
Нажать «Стоп» мгновенно после старта.
Ожидаемый результат:
Программа блокирует сохранение пустой сессии (ошибка или предупреждение), так как нельзя записать 0 минут.
Данные в историю не попали.
Постусловия: Система осталась в исходном состоянии.
Функция 2 и 4: Отчеты и фильтрация по датам
Кейс 1. Позитивный: Просмотр отчета за конкретный месяц
Связанная функция: Фильтрация отчета по диапазону дат.
Приоритет: Высокий.
Предусловия: В программе есть записи за октябрь 2026 года.
Тестовые данные: Начальная дата — 01.10.2026, конечная дата — 31.10.2026.
Шаги выполнения:
Зайти в меню отчетов.
Выбрать период с первого по тридцать первое октября.
Нажать кнопку «Фильтр».
Ожидаемый результат:
На экране появился список задач.
Видна задача «Лабораторная» с общим временем 45 минут.
Постусловия: Без изменений (просто просмотр).
Кейс 2. Негативный: Неверный порядок дат
Связанная функция: Проверка ввода при фильтрации.
Приоритет: Высокий.
Предусловия: Приложение запущено.
Тестовые данные: Начальная дата — 20.10.2026, конечная дата — 12.10.2026 (начало позже конца).
Шаги выполнения:
Ввести даты так, чтобы вторая была меньше первой.
Нажать «Фильтр».
Ожидаемый результат:
Программа выдает ошибку: «Некорректный диапазон дат».
Отчет не формируется, запрос не выполняется.
Постусловия: Экран остается прежним.
Кейс 3. Граничный: Период, где нет никаких записей
Связанная функция: Обработка пустого результата.
Приоритет: Средний.
Предусловия: В базе нет записей за январь 2027 года.
Тестовые данные: Начальная дата — 01.01.2027, конечная дата — 31.01.2027.
Шаги выполнения:
Выбрать будущий период, в котором точно не было работы.
Нажать «Фильтр».
Ожидаемый результат:
Программа возвращает пустой список.
Появляется сообщение: «В заданном периоде нет записей».
Приложения не падает.
Постусловия: Без изменений.
Функция 3: Заметки
Кейс 1. Позитивный: Создание новой заметки
Связанная функция: Добавление информации.
Приоритет: Высокий.
Предусловия: Пользователь находится в меню задач.
Тестовые данные: Название «Математика», содержание «Решение примеров».
Шаги выполнения:
Нажать кнопку «Добавить заметку».
Ввести название и текст.
Сохранить.
Найти эту заметку в списке.
Ожидаемый результат:
Заметка успешно создана и появилась в общем списке.
Дата создания проставилась автоматически текущей.
Постусловия: В системе стало на одну заметку больше.
Кейс 2. Негативный: Пустое название заметки
Связанная функция: Запрет пустых полей.
Приоритет: Высокий.
Предусловия: Открыто окно создания заметки.
Тестовые данные: Название оставлено пустым, текст введен («Любой текст»).
Шаги выполнения:
Оставить поле названия пустым.
Нажать «Сохранить».
Ожидаемый результат:
Программа запрещает сохранение.
Выдается предупреждение, что название не может быть пустым.
Постусловия: Новая заметка не создана.
Кейс 3. Граничный: Удаление заметки, к которой привязана задача
Связанная функция: Безопасное удаление связей.
Приоритет: Высокий.
Предусловия: Задача «Лабораторная» привязана к заметке «Базы данных».
Тестовые данные: Удаляемая заметка — «Базы данных» (ID 1).
Шаги выполнения:
Выбрать заметку «Базы данных».
Нажать «Удалить».
Проверить задачу «Лабораторная».
Ожидаемый результат:
Заметка удалилась из списка.
Задача «Лабораторная» НЕ удалилась вместе с ней.
У задачи пропала категория/привязка (стало пусто или «Без категории»), но сама задача осталась целой.
Постусловия: Связь разорвана безопасно, данные задачи сохранены.
Функция 5: Задачи
Кейс 1. Позитивный: Создание новой задачи
Связанная функция: Добавление нового элемента.
Приоритет: Высокий.
Предусловия: Пользователь в меню задач.
Тестовые данные: Текст задачи «Выучить билеты 1-10», привязка к заметке «Базы данных».
Шаги выполнения:
Нажать «Добавить новую».
Ввести текст и выбрать категорию.
Сохранить.
Ожидаемый результат:
Новая задача появилась в списке.
Статус выполнения у нее по умолчанию «Нет» (не выполнена).
Постусловия: В списке стало на одну задачу больше.
Кейс 2. Негативный: Удаление задачи с историей времени
Связанная функция: Защита важных данных.
Приоритет: Высокий.
Предусловия: У задачи «Лабораторная» уже есть записанное время (45 минут).
Тестовые данные: Удаляемая задача — «Лабораторная» (ID 1).
Шаги выполнения:
Выбрать задачу «Лабораторная».
Нажать «Удалить».
Ожидаемый результат:
Программа блокирует удаление.
Выдается сообщение: «Нельзя удалить задачу, у которой есть история времени».
Задача и ее статистика остаются на месте.
Постусловия: Данные защищены от случайной потери.
Кейс 3. Граничный: Удаление новой задачи без истории
Связанная функция: Стандартное удаление.
Приоритет: Средний.
Предусловия: Создана новая задача «Выучить билеты», у нее еще нет записанного времени.
Тестовые данные: Удаляемая задача — «Выучить билеты» (ID 3).
Шаги выполнения:
Выбрать свежую задачу.
Нажать «Удалить».
Ожидаемый результат:
Задача успешно удаляется из списка.
Никаких ошибок не возникает.
Постусловия: Лишняя запись удалена, список обновлен.
